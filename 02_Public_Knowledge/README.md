# 02_Public_Knowledge

本目录保存经核验的公开法律资料及其索引，例如法律法规、司法解释、司法文件、指导性案例、典型案例和法院指引。

当前阶段只建立框架，不批量下载或填充内容。新增资料时：

1. 优先选择官方、稳定、可核验来源；
2. 在 `sources_registry.md` 登记来源、效力/可靠性、范围和最近核验日期；
3. 保存原始来源或稳定链接，不只保存 AI 摘要；
4. 记录版本、生效/失效时间和适用法域；
5. 二手资料只用于导航或观点发现，关键法律结论尽量回到官方原始来源；
6. 不得混入真实案件事实、客户材料或内部策略。

未来允许使用的法律数据库与补充来源属于律师审阅项，见 `docs/LAWYER_REVIEW.md` 的 LR-06。
