# 03_Private_Knowledge

本目录保存律师自己的通用专业认识与方法：

- `playbooks/`：可复用的工作方法与决策框架；
- `strategy_notes/`：一般策略方法，不含某案未脱敏事实；
- `issue_notes/`：专题法律或证据问题笔记；
- `industry_knowledge/`：行业、交易和业务知识。

Private Knowledge 与 Experience 不同：Knowledge 是一般认识和方法；Experience 必须能追溯到真实执业经验、经过必要脱敏，并记录其来源与律师验证状态。

本目录默认被 `.gitignore` 排除具体内容。除非律师明确确认完成脱敏、具有处理权限且允许进入相应远程仓库，否则不得推送到公共 Git 远程仓库或上传外部服务。
