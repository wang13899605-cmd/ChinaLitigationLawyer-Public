# 汪佳成诉讼律师自动化工作流网站

本网站是 `ChinaLitigationLawyer` 的本地可视化工作台，固定绑定 `127.0.0.1`，不对外发布。

## 使用

双击项目根目录的 `启动工作流网站.cmd`。浏览器打开后可：

- 查看 `docs/LITIGATION_LIFECYCLE_ACTION_MATRIX.md` 中的全部阶段与动作；
- 查看 `01_Skills/` 的当前版本、状态、职责及流程调用关系；
- 查看、筛选及下载 `TEMPLATE_INDEX.yaml` 中登记的模板副本；
- 上传新模板或更新版本到 `05_Templates/_Incoming/`；
- 登记工作流问题并复制为可交给 Codex 的修订指令。

## 数据原则

- 工作流、Skill 和模板清单每次刷新都从母项目实时读取，网站不保存第二套权威副本。
- 上传文件先进入待处理区，不自动成为活动母版；须完成脱敏、版式核验、模板ID/索引更新和律师确认。
- 问题反馈保存在 `10_Logs/workflow_feedback_queue.json`，默认不进入Git，避免误录案件敏感信息。
- 网站不得替代律师审批、Skill回归、模板质量检查或项目变更日志。
