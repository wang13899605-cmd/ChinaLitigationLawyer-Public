# 如何新增或更新模板

你不需要编辑 YAML、Markdown 或写固定格式的长指令。把参考文件放在一个明确的本地文件夹，然后用自然语言告诉 Codex即可。

## 新增模板时

建议直接说：

> 请把 `C:\你的路径\模板新增` 中的文件完成脱敏后加入 ChinaLitigationLawyer 的模板库。按文书类型归类，Word 原文件作为版式母版；更新模板目录、机器索引和自动选择规则。若与现有模板用途重复，先比较适用场景和版式，再决定升级、并存或不纳入。完成隐私扫描和逐页渲染后，告诉我仍需确认的事项。

## 更新指定模板时

建议直接说：

> 请用 `C:\你的路径\新版起诉状.docx` 更新模板 `TPL-COM-002`。比较字段、内容结构和版式变化，完成脱敏和逐页回归检查；更新索引与变更记录。不要直接删除旧版，如需替换请先把旧版归档，并告诉我哪些变化需要律师确认。

## Codex 应自动完成

1. 只读盘点来源，识别文件类型、重复和敏感信息；
2. 脱敏正文、表格、页眉页脚、批注、修订、脚注、元数据和外部链接；
3. 保留 DOCX 作为正式母版，用语义占位符替换案件信息；
4. 比较同用途模板，确定新增、升级或并存，而不是机械覆盖；
5. 更新 `TEMPLATE_INDEX.yaml`、目录和复核清单；
6. 用 Word 兼容方式逐页渲染，复核字体、行距、编号、表格和分页；
7. 不移动、不改写来源文件，不把真实案件事实带入模板库。
8. 仅在脱敏、包级隐私检查、逐页版式核验及索引登记全部通过后，将该DOCX加入`.gitignore`逐文件白名单；只允许进入已核实权限受控的私有Git，不得因文件位于模板目录就自动跟踪或推送。
