# 律师最终审查清单

## 事实与主体

- [ ] 当事人名称、统一社会信用代码/身份信息、诉讼地位、代理权限准确。
- [ ] 重要事实均能回溯到当前 Matter 的证据；没有跨案污染。
- [ ] 当事人陈述、对方主张、AI 推论、未知和冲突没有被写成确定事实。
- [ ] 日期、金额、履行过程、程序进展与原始材料一致。

## 证据

- [ ] Evidence ID、文件名、页码/位置和引用内容对应。
- [ ] 已检查完整上下文、附件、版本、重复件、缺页和 OCR 错误。
- [ ] 已识别不利证据、相反证据、真实性/合法性/关联性争议与证据缺口。
- [ ] 证明目的没有超出证据合理含义。

## 法律与程序

- [ ] 法律名称、条款、机关、效力状态、适用时间与法域已核验。
- [ ] 案例的法院、案号、日期、审级、案由、状态和参考层级已核验。
- [ ] 关键结论没有只依赖二手文章或模型记忆。
- [ ] 管辖/仲裁、诉讼时效、除斥期间、举证和上诉等期限已独立复核。
- [ ] 已考虑最强反方观点、例外规则和不利程序后果。

## 请求、策略与金额

- [ ] 最终请求、抗辩、反请求和请求权基础由律师确认。
- [ ] 重大事实承认、权利放弃、和解、保全、鉴定等决定由律师确认。
- [ ] 金额计算保留输入、规则、公式、期间、利率、舍入、来源和验证状态。
- [ ] 主位、备位与最低方案的前提和风险明确。

## 文书与审批

- [ ] 文书用途、接收方、模板、法院/仲裁机构格式和篇幅要求正确。
- [ ] 引文、附件、证据目录和正文交叉引用一致。
- [ ] 个人信息、商业秘密和客户敏感内容已按用途做最小必要披露/脱敏。
- [ ] 文件版本和状态准确；AI 未擅自标记 LAWYER_APPROVED 或 FINAL。
- [ ] 对外发送、提交、签署、盖章或发布已获得实际授权。
