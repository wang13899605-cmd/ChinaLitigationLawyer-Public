### 2. 覆盖标记

- `完整`：现有 Skill 已包含该动作的主要方法、输出和边界。
- `部分`：现有 Skill 能辅助，但缺少该任务专属判断或稳定输出。
- `规则/工具`：由 AGENTS、Rules、Schema、模板或通用文件工具处理，不值得单独建 Skill。
- `缺失`：要达到预期自动化效果，现有体系没有足够方法支撑。
- `draft`：Skill、输出规则和合成测试已建立，但尚未经过历史Matter或Gold Standard行为回归，不能视为律师验证完成。
- “需要专用 Skill”是对自动化可靠性的判断，不表示律师可以把专业责任交给 Skill。

| G14-A11 | 涉及重大事实、对外立场、金额、程序选择或已批准版本可能变化时，AI先提出有依据的初步分析，再提交律师决定。 | 等待决定期间继续完成不受影响的工作。 |

### G14-B. 增量传播、版本与复核（律师已全部确认）

| ID | 已确认标准 | 执行边界 |
|---|---|---|
| G14-B01 | 为每次增量处理建立批次记录，关联触发材料、接收时间、影响范围和处理状态。 | 重复触发复用既有批次/对象ID，不重复处理。 |

## 四、现有 Skill 覆盖结论

### 已基本形成闭环

1. Matter建立、原始材料隔离和初步文书计划：S1。
2. 事实时间轴、冲突版本和来源定位：S2。
3. 请求/抗辩要件与事实证据矩阵：S3。
4. 中国法研究、法源效力和引文核验：S4。
5. 假设、遗漏、不利材料和幻觉审计：S5。

7. 律师问题、决定和输出状态门控：S7。
8. 保密、脱敏、跨Matter和外部传输检查：S8。
9. 金额、表格、分类和格式勾稽：S9。

### 现有体系的关键误区

- G8 v0.1.0 draft负责从当前Matter分析生成文书，S6负责已有草稿的独立质检；二者职责不同，均未经过真实Matter行为回归。
- G5 v0.1.0 draft负责发现、筛选、比较和推荐请求/抗辩方案；S3负责要件—事实—证据检验。两者均不得自行决定最终请求、抗辩、承认或放弃。
- S1负责Matter接收与建立；G2 v0.1.0 draft已补充深度访谈、口头描述法律化、原话保存及不利事实追问，两者按前后阶段组合。
- G3 v0.1.1 draft已将证据追溯、三性、完整性、证明作用、单证与证据链、对方质证、补强方案及补充证据两段式接收连成一体；F12、F14保留律师确认门槛。
- G4 v0.1.0 draft已建立期限计算、复核、提醒授权和增量重算框架，并配套Matter台账与确定性计算工具；尚未经过历史Matter或Gold Standard行为回归。
- G10 `v0.1.1 draft`已覆盖律师确认的庭前双文书、法条完整原文、对方证据质证准备、程序选项、模拟发问及庭后来源化整理；仍需历史Matter或Gold Standard行为回归。调解、上诉、执行和结案尚无完整项目专属Skill。
