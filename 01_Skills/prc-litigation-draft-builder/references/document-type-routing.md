# Document-type routing

Use the current `05_Templates/TEMPLATE_INDEX.yaml` for actual availability and eligibility. The table identifies drafting emphasis, not a prescribed heading list or entitlement to file. Recheck forum-specific requirements and the current Matter's instructions.

| Document family | Existing template examples | Distinct drafting control |
|---|---|---|
| Civil complaint | `TPL-COM-002` | Default new-draft mother. Title is only `民事起诉状`; do not add a cause-of-action line or subtitle beneath it. Preserve the mother's font, page, numbering, paragraph and signature layout. Each relief has claimant, obligor, legal basis, fact/evidence links, amount/formula and order; jurisdiction from G19 and any claim structure from lawyer-confirmed G5 decision. `TPL-COM-001` is historical only. |
| Civil defense | `TPL-DEF-001` | Respond to each opposing request and decisive factual allegation; classify admission/denial/non-dispute/reservation; material admission or waiver is lawyer-controlled. |
| Counterclaim | None currently indexed | Independent claim, parties, legal basis, relief, connection to original claim and G4 procedural deadline; do not use a complaint template blindly. |
| Civil appeal | `TPL-APP-001` | Identify challenged disposition, requested second-instance action, grounds tied to the judgment and record, and G4 appeal deadline; new evidence/procedural limits need current-rule research. |
| Arbitration application | `TPL-ARB-001` | Verify arbitration agreement, institution and applicable rules; in bilingual drafting, align parties, relief, amounts, definitions and law and retain translation-review status. |
| Preservation or online asset inquiry/control | `TPL-PRV-001`, `TPL-PRV-002` | Match applicant, requested measure, object, amount, necessity, evidence, jurisdiction and security/undertaking where applicable; substantive preservation decision remains lawyer-controlled. |
| Evidence catalog, supplement, examination opinion | `TPL-EVD-001`–`003` | Match Evidence IDs, source, proof purpose and counterpart position; do not convert an AI evidentiary assessment into a court finding. In an evidence catalog or supplement, `页码` is the inclusive position of each evidence group in the final continuously paginated evidence bundle: write `1-3`, `4-6`, or a single page such as `7`, never `3页` or another page-count expression. If the evidence bundle order or pagination is not final, use `待编页` in the review draft and synchronize the ranges only after the bundle is assembled. |
| Legal research report | `TPL-RES-001` (default four-column case table), `TPL-RES-002` (detailed six-column table) | Answer concrete research questions through concise facts, full verified law, supporting/limiting cases, analysis, risk and preliminary conclusions. Keep original-law blocks separate from analysis. Use the six-column table when dates and outcomes need explicit comparison. |
| Hearing outline and separate legal-authority compilation | `TPL-HRG-002`, `TPL-LAW-003` | Internal reference documents; copy complete verified original text of every cited article, with source/version metadata outside the quotation. The legal-authority compilation groups sources by issue, claim or requested relief and contains no case analysis or strategy. |
| Counsel submission and post-hearing supplement | `TPL-SUB-001` | Tie each issue to pleadings, hearing record, admitted/disputed facts, evidence and verified authority; a lawyer note is not an official court transcript. |
| Power of attorney and firm representation documents | `TPL-ENG-001`–`003` | For `TPL-ENG-001`, use the lawyer-approved mother and special authorization by default unless the lawyer instructs otherwise; verify client, counsel, matter description and date. Never sign or stamp. Other firm-specific templates remain subject to their review status. |
| Lawyer letter or other missing type | None currently indexed | Record template gap, use the project no-template style only if appropriate, and mark `REVIEW_REQUIRED`. Substantive purpose and audience still govern content. |

Do not turn this drafting Skill into preservation analysis (G7), appeals strategy (G12), arbitration procedure (G18), negotiation (G11), or filing/service operations (G9). Use available upstream analysis or open a scoped lawyer question when these decisions are material.
