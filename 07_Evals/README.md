# 07_Evals

本目录用于回答一个核心问题：系统或 Skill 的修改是否在真实任务上可观察地变好，而不是“感觉更聪明”。

- `eval_rubric.md`：统一评价维度和重大错误门槛；
- `regression/`：经脱敏、可重复运行的历史任务与隔离的期望结果；
- `results/`：每次评测的模型/工具版本、输入集、指标、错误和比较结果。

## 基本纪律

1. 实质性 Skill 修改后，至少使用一个既有测试 Matter 或 Gold Standard 回归。
2. 修改者不能只凭主观感觉自评；优先使用预先定义的标准、盲评或独立律师复核。
3. 保留修改前基线、修改后结果、改善、退化和 Critical Error。
4. 新版如未改善或引入重大错误，应回退或保持 testing，不得为证明修改有效而改写评分标准。
5. 回归集不得包含未获授权的敏感材料；标准答案与模型输入应隔离。
