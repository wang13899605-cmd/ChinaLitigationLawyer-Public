# 04_Experience

Experience 不是案件摘要，而是从真实案件中抽象出的可复用经验。它应帮助未来案件发现问题、提出策略或识别失败模式，但绝不能把历史案件事实带入当前 Matter。

## 生命周期

1. 从已处理 Matter 形成脱敏草稿；
2. 放入 `pending_review/`，保留 Source Matter、匿名化状态和证据基础；
3. 律师审查可复用性、偏差、保密与脱敏；
4. 只有确认后才进入 `validated/`；
5. 发现法律变化、经验失效或过度概括时，降级、修订或废弃。

未经律师审核的 Experience 不得标记为 validated。即使已匿名化，除非律师明确允许，也不得推送到公共 Git 远程仓库或提供给外部服务。

具体匿名化标准属于律师审阅项，见 `docs/LAWYER_REVIEW.md` 的 LR-07。
