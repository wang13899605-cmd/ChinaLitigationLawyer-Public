# 05_Templates

本目录保存经脱敏、核验并纳入索引的 Word 文书母版。`DOCX` 是版式权威来源；Markdown/YAML 只保存目录、适用条件和选择规则，不能替代 Word 母版。

模板优先来源：

1. 律师本人长期使用并确认的格式；
2. 法院、司法机关或仲裁机构的官方示范文本；
3. 经律师验证、完成必要脱敏的优秀历史文件。

每个模板应记录来源、版本、适用法域/程序、最后核验日期、已知限制、是否含示例事实。模板中的事实、金额、案号和论证不得自动成为新 Matter 内容。

运行入口：

- `TEMPLATE_INDEX.yaml`：供 Codex 选择模板的机器可读索引；
- `TEMPLATE_CATALOG.md`：供律师查看的模板清单；
- `TEMPLATE_REVIEW.md`：仍需律师二次确认的集中清单；
- `TEMPLATE_QA.md`：本次脱敏和版式核验结果；
- `00_System/Rules/09_template_selection_and_fidelity.md`：选模、填充和版式复核规则。

索引中标为`enabled_for_ai_draft: true`的母版允许用于 `AI_DRAFT` 或 `REVIEW_REQUIRED` 草稿；停用旧版仅供回溯。只有律师明确批准的具体案件版本才能进入 `09_Final/`。使用时必须复制母版到 Matter，不得直接覆盖本目录中的母版。

民事起诉状新稿使用 `complaint/TPL-COM-002_民事起诉状_真实版式脱敏母版.docx`。标题仅写“民事起诉状”，标题下不写案由或副标题，直接进入当事人信息；字体、字号、页面、编号、段落与签署格式以该DOCX为准。TPL-COM-001仅供历史回溯。

庭前材料中，新稿的庭审提纲使用 `hearing/TPL-HRG-002_民商事庭审提纲_法条原文母版.docx`；法律规定整理/法律法规汇编另用 `legal_authority/TPL-LAW-003_法律规定整理_诉请争点对应_脱敏母版.docx`。两者的法条栏目均须逐条照录经核验的适用版本完整原文，保留全部款项及标点；法规汇编不写案例或适用分析。旧版TPL-LAW-001/002只供回溯。

法律检索报告使用 `legal_research/TPL-RES-001_法律检索报告_四列案例表_脱敏母版.docx`；需要把裁判日期和裁判结果作为独立比较字段时使用 `TPL-RES-002_法律检索报告_六列案例表_脱敏母版.docx`。报告应围绕具体问题形成案情、完整法条、案例、分析、风险及初步结论，且分析与法条原文明确分隔。不得使用TPL-LAW-003替代法律检索报告。

本目录是公开准备副本。23份DOCX已做本地技术脱敏检查，旧版TPL-COM-001、TPL-ENG-001/002、TPL-HRG-001及TPL-LAW-001/002停用、仅供版式追溯；启用的17份可用于待审草稿。技术脱敏不等于取得公开授权，公开前仍须完成`TEMPLATE_REVIEW.md`所列人工、权属、版式和跨文件检查。不得据此直接推送到公开远端。
