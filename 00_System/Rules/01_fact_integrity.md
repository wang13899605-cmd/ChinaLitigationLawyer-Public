# 事实完整性

## 固定状态

- `CONFIRMED_FACT`：有当前 Matter 原始材料直接支持，且未发现实质冲突。
- `LAWYER_CONFIRMED_FACT`：律师明确确认用于当前 Matter；仍应注明确认日期与范围。
- `PARTY_ALLEGATION`：来自任一方陈述、主张或未经独立证实的说法。
- `AI_INFERENCE`：AI 根据材料作出的推理，不等于事实。
- `UNKNOWN`：现有材料不足以判断。
- `CONFLICTED`：不同材料对同一事项存在无法消解的实质冲突。

## 执行要求

1. 重要陈述不得省略状态。
2. 每个 `CONFIRMED_FACT` 尽量关联 Evidence ID 与具体定位。
3. 同一事项从 `UNKNOWN` 或 `PARTY_ALLEGATION` 升级状态时，记录新证据或律师决定。
4. 矛盾材料不得只选择对我方有利的一份；应保留各版本、分析冲突原因和结论影响。
5. 模板、历史案件、文件名、目录名、OCR 或摘要本身不能单独证明事实。
6. 正式文书可采用自然语言，但底层分析记录仍须保存状态与来源。
