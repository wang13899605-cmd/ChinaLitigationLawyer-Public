# 输出状态

| 状态 | 含义 | 谁可赋予 |
|---|---|---|
| `AI_DRAFT` | AI 工作稿，尚未完成全部质量检查 | AI 或律师 |
| `REVIEW_REQUIRED` | 已达到可审阅程度，但存在需律师核验/决定事项 | AI 或律师 |
| `LAWYER_APPROVED` | 律师已明确批准当前版本及用途 | 仅律师 |
| `FINAL` | 律师确认可作为指定用途的最终版本 | 仅律师 |

## 规则

- 状态应与版本号、日期、审阅人和批准用途同时记录。
- 任何实质修改都会使既有批准失效，除非律师明确说明批准覆盖该修改。
- 文件名中的“定稿”“最终”“盖章版”等文字不自动证明状态。
- 对外发送、提交、签署或发布仍需遵循实际授权；`FINAL` 不等于已获发送权限。

对外文件的最终审批规则属于律师审阅项，见 `docs/LAWYER_REVIEW.md` 的 LR-04。
