# 证据可追溯性

## Evidence ID

- 每个 Matter 内使用唯一编号，例如 `E-0001`。
- 同一原始文件只建立一个主记录；文件中的独立附件、页段或数据行可建立子定位。
- 重复件应标记与主记录的关系，不得造成证据数量虚增。

## 最低记录

每份证据至少记录文件名、相对路径、类型、日期/主体（如可确认）、摘要、支持/反驳事项、真实性状态、原文定位和审阅状态。

## 来源纪律

1. 引用重大事实时，优先给出 Evidence ID + 文件名 + 页码/表格行/消息时间等定位。
2. OCR、AI 摘要、转录和提取表属于衍生内容；发生差异时回到原始证据。
3. 不得修改 `00_Original`；校正 OCR、批注或裁剪件保存到后续目录并注明派生关系。
4. 不能精确分页的文件，应采用可复现定位方式，例如标题、段落首句、时间戳或工作表与单元格。
5. 证据链断裂或来源不可定位时，结论至少标记 `REVIEW_REQUIRED`。
