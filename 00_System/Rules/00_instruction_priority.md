# 指令优先级

## 目的

在多个指令来源并存时，确保模型选择可解释、可追踪，不进行静默覆盖。

## 执行

1. 先遵守平台系统规则、强制安全规则和实际工具权限。
2. 项目内部依次适用：当前律师明确指令 → 当前 Matter 的有效律师决定 → Matter 专属指令 → 根目录 `AGENTS.md` → 适用 Skill → 已验证知识/经验 → 模型一般知识。
3. “更新、更具体”只有在同一优先级内才通常优先；不得用更新的低优先级内容覆盖高优先级内容。
4. 发现实质冲突时记录：冲突来源、各自主张、暂定处理、受影响输出、是否需要律师决定。
5. 不影响当前工作的冲突可标记后继续；影响请求、抗辩、核心事实、程序、金额或对外立场的冲突进入律师问题闭环。
